# adamkucharczyk.pl

Personal site of Adam Kucharczyk, IT architect: professional profile, architecture consulting
and training as a competence. Polish.

Eleventy 3 static site, CUBE CSS with design tokens, deployed by Netlify on push to `main`.

- Development rules: [`docs/guidelines.md`](docs/guidelines.md)
- Structure and commands: [`AGENTS.md`](AGENTS.md)

```bash
npm install
npm start           # dev server with watch
npm run build       # production build into dist/, with dead-link check
```
